# Sandy Games موقع صنع بواسطة ساندي!

موقع بسيط يجمع مجموعة ألعاب صغيرة ممتعة بواجهة عربية موحدة.

## نظرة عامة

Sandy Games هو موقع تجريبي يهدف لتقديم تجربة لعب سريعة وممتعة لمجموعة من الألعاب الصغيرة. يحتوي الموقع على صفحة رئيسية تضم:

- قسم تعريفي بالموقع.
- روابط للألعاب الحالية والمخطط لها.
- تعليمات عامة للاعبين.
- معلومات حول الموقع وسياسته العامة.

## البدء المحلي

1. استخدم أي خادم ثابت (static server) لعرض الملفات، مثل:
   ```bash
   npx serve .
   ```
2. افتح المتصفح وتوجه إلى `http://localhost:3000` أو العنوان الذي يوفره الخادم.

يمكنك أيضًا فتح ملف `index.html` مباشرة في المتصفح، لكن بعض الخصائص (مثل الخطوط المستوردة) قد تتطلب اتصالًا بالإنترنت.

## الهيكل

```
.
├── index.html        # الصفحة الرئيسية للموقع
├── app.js            # شيفرة JavaScript للتفاعلات الخفيفة

│   └── styles.css    # الأنماط المشتركة
```

## التخصيص والتطوير

- أضف ألعابًا جديدة بإنشاء بطاقات أو صفحات فرعية وربطها عبر قسم الألعاب.
- يمكن إضافة ملفات CSS أو JS إضافية داخل مجلد `assets/` حسب الحاجة.
- لا تنس تحديث هذا الملف (README) عند إضافة ألعاب أو تعليمات جديدة.
