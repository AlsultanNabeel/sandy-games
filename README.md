# Sandy Games موقع صنع بواسطة ساندي!

موقع بسيط يجمع مجموعة ألعاب صغيرة ممتعة بواجهة عربية موحدة، مبني بـ HTML و CSS و JavaScript فقط
(بدون مكتبات ولا أدوات build ولا موارد خارجية).

**النسخة المنشورة:** https://alsultannabeel.github.io/sandy-games/

## الألعاب

| اللعبة | الوصف | الفوز / الخسارة |
| --- | --- | --- |
| 🔢 [تخمين الرقم](games/guess-number/index.html) | خمّن رقمًا سريًا من 1 إلى 100 مع تلميحات أعلى/أقل | تخمين صحيح خلال 10 محاولات / نفاد المحاولات |
| ✋ [حجر ورقة مقص](games/rock-paper-scissors/index.html) | مباراة ضد الحاسوب | أول من يصل إلى 3 انتصارات |
| ⏱️ [اختبار سرعة النقر](games/reaction-test/index.html) | انقر فور تحوّل اللون للأخضر | أقل من 400 مللي ثانية / نقر مبكر أو بطيء |
| 🧠 [لعبة الذاكرة](games/memory/index.html) | اقلب البطاقات وطابق الأزواج | 8 أزواج خلال 20 محاولة / نفاد المحاولات |
| ❌ [X-O](games/tic-tac-toe/index.html) | إكس-أو ضد الحاسوب | صف من 3 علامات قبل الحاسوب |

كل لعبة فيها زر لإعادة اللعب وزر للعودة إلى الصفحة الرئيسية.

## التشغيل المحلي

لا يحتاج المشروع أي تثبيت. شغّل أي خادم ملفات ثابت من جذر المشروع:

```bash
python3 -m http.server 8000
# أو
npx serve .
```

ثم افتح `http://localhost:8000`. يمكنك أيضًا فتح `index.html` مباشرة في المتصفح.

جميع المسارات نسبية، لذلك يعمل الموقع كما هو على GitHub Pages تحت `/sandy-games/`.

## الهيكل

```
.
├── index.html                # الصفحة الرئيسية
├── app.js                    # تفاعلات خفيفة مشتركة (تمرير سلس، سنة الفوتر)
├── assets/
│   └── styles.css            # الأنماط المشتركة للموقع وصفحات الألعاب
└── games/
    └── <اسم-اللعبة>/
        ├── index.html        # صفحة اللعبة (نفس الهيدر والفوتر)
        └── <اسم-اللعبة>.js   # منطق اللعبة
```

## إضافة لعبة جديدة

1. أنشئ مجلدًا `games/<اسم>/` فيه `index.html` و `<اسم>.js` (انسخ بنية لعبة موجودة).
2. استخدم مسارات نسبية فقط (`../../assets/styles.css`، `../../index.html`).
3. أضف بطاقة للعبة في قسم الألعاب داخل `index.html`، وحدّث هذا الملف.
